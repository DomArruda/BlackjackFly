## Data Attribution
The anatomical synaptic weights used in `real_malecns_weights.npz` are derived from the 
**male-cns:v1.0** connectome dataset produced by the FlyEM Project Team at HHMI's Janelia 
Research Campus, the Cambridge Connectomics Group, and Google Research.

Data accessed via [neuPrint](https://neuprint.janelia.org) and licensed under [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/).
